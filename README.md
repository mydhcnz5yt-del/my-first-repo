# 我的个人主页

这是我的第一个 GitHub 项目：一个个人介绍网页。

## 这个项目是什么

一个用 HTML + CSS 写成的单页个人主页，包含：

- 顶部自我介绍区域
- 关于我
- 技能标签
- 兴趣爱好
- 联系方式

## 怎么修改它

打开 `index.html`，所有需要修改的地方都标了 `【改我】` 注释：

1. 把你的名字写进标题
2. 把"关于我"的段落改成自己的介绍
3. 把技能标签和兴趣爱好改成你真实的
4. 把联系方式的 GitHub 链接和邮箱换成你的

改完保存，用浏览器双击打开 `index.html` 即可预览效果。

## 怎么部署成免费网站

1. 把这个仓库推送到 GitHub（Commit + Push）
2. 打开仓库页面 → Settings（设置）→ Pages（页面）
3. Source 选择 `main` 分支 → Save（保存）
4. 等一两分钟，你的网站就上线了，地址是：

```
https://你的用户名.github.io/仓库名/
```

## 技术栈

- HTML5
- CSS3（纯手写，没有用任何框架）
